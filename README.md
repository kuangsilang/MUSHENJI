# 牧神记 · 编年史

《牧神记》（宅猪 著）同人向 **3D 可交互编年史网站**：玄墨鎏金古风 + 动漫感粒子特效，
把原著与 B站/玄机科技动画年番的世界观做了一次深度视觉化整理。

![views](https://img.shields.io/badge/视图-5-brown) ![tech](https://img.shields.io/badge/Three.js-r186-blue) ![deps](https://img.shields.io/badge/运行依赖-0-brightgreen)

## 启动

```bash
cd mushenji
npm start        # = node server.js，无任何第三方运行依赖
# 打开 http://localhost:8178
```

> 首次加载会从 Google Fonts 拉取「马善政毛笔楷书 / 思源宋体」，离线时自动回退到系统楷体/宋体。

## 目录结构

```
mushenji/
├── index.html            # 入口（importmap 指向本地 three.js）
├── css/style.css         # 玄墨鎏金视觉体系
├── js/
│   ├── data.js           # 全部内容数据（纪元/事件/人物/区域/境界/势力/档案）
│   ├── art.js            # 皮影剪影立绘、势力徽记、区域图标的 SVG 生成器
│   ├── engine.js         # 渲染器/Bloom 后期/场景切换/相机补间/标签投影
│   ├── app.js            # 导航、水墨转场、详情抽屉、HUD
│   ├── lib/three/…       # 本地化 three.js r186 及后期处理模块
│   └── scenes/           # hero / timeline / stars / map / ladder 五个场景
└── server.js             # 零依赖静态服务器
```
